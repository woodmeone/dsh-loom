# ADR-0003：块目录是提示词的唯一真相源

- 状态：已接受
- 日期：2026-10-18

## 背景

现役机制里有**三层真相**，层层回退：

```
提示词框自改  >  $DSH_HOME/prompt-inject.md  >  lib/asset-table.js 里的加密默认稿
```

盘上那一份的状态由 `$DSH_HOME/dsh-purge/override-state.json` 记录（`{customized, hash, seedHash, updatedAt}`），判定逻辑在 `lib/core.js`：

```js
export function looksLikePluginDefault(text) {
  const n = normalizeOverride(text);
  if (!n) return false;                                  // 空 → 不是插件默认
  if (n === normalizeOverride(defaultOverrideText())) return true;
  return PLUGIN_DEFAULT_MARKS.every((mark) => n.includes(mark));
}

export function isKeepableUserOverride(dshHome, text) {
  const incoming = normalizeOverride(text);
  if (!incoming) return false;                           // 空 → 也不是用户自改
  ...
}
```

这套机制曾经出过事故：`PLUGIN_DEFAULT_MARKS` 里用一个会被人设替换掉的字串当标记，导致用户改稿每次启动都被判定成「非用户自改」而反复被 seed 覆盖。

而且它**拦不住空文件**：空文本在 `looksLikePluginDefault` 和 `isKeepableUserOverride` 里都返回 `false`，落在两条判定之间，只能靠「永不空串」兜底把它救成加密默认稿。

## 决策与取舍

**块目录（`blocks/<id>.md` + `config.json`）成为提示词的唯一真相源。`prompt-inject.md` 与加密默认稿机制在提示词层废弃。**

放弃了：**保留 `prompt-inject.md` 当「出厂块包」。** 两份内容会漂移——磁盘上已经有五代同名文件（25,128 B 两份、25,828 B 一份、34,296 B 一份），这就是前车之鉴。

## 后果

- `override-state.json` 的盯梢对象要从**一个文件的哈希**换成**块目录的哈希集合**。目录里增删改都会换哈希，比单文件更钝——校验时机要重新设计。
- `scripts/embed-default-prompt.mjs` 与 `lib/asset-table.js` 的加密表**在提示词层失去用途**。它们是否还有别的消费者，迁移前要确认。
- 现有用户的 `prompt-inject.md`（22,343 字）需要**一次性迁移**成默认块。迁移是票4 的内容。
- 「恢复出厂」的语义变了：不再是「回到加密默认稿」，而是「回到随插件发行的块目录内容」。
- 三层真相压成一层。以后新增真相层要先过这条 ADR。
